# Game Builder Agent

A chat-first assistant for Fortnite UEFN, Roblox Studio, standalone Unreal Engine 5, and Unity. Describe the game and feature in plain language; the agent returns build steps, correctly placed Verse, Luau, C++, or C# code, and an asset list. The Unreal Engine and Unity manuals are drafts and are not official kits until each has been used for a real build session and approved by the editor.

See [SETUP.md](SETUP.md) for local setup, API configuration, and Render deployment.
